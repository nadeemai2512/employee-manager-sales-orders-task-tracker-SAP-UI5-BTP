# SAP BTP + SAPUI5 sample projects

| Project | What it shows |
|---|---|
| employee-manager | CRUD with associations, Select with data from a second entity, filters, OData function |
| sales-orders | Routing (list to detail), deep insert, bound actions, server calculations |
| task-tracker | IconTabBar, status workflow via bound action, summary function |

Each folder is an independent project. Run any of them:

    cd <project>
    npm install
    npm start

then open the URL given in that project's README (all use http://localhost:4004).
Requires Node.js 18+ and internet access (UI5 loads from https://ui5.sap.com).
